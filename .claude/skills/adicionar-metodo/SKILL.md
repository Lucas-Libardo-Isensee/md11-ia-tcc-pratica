# Skill: Adicionar novo método ao GerenciadorDeTarefas

Quando eu pedir para adicionar um novo método neste projeto:
- Siga o mesmo estilo dos métodos existentes (Adicionar, Concluir, Listar).
- Use a tupla (Id, Titulo, Concluida) já existente, não crie uma classe nova.
- Escreva o método em português, seguindo PascalCase.
- Adicione um comentário curto acima do método explicando o que ele faz de fato, sem repetir o nome do método.
- Mantenha o mesmo padrão de percorrer a lista com `for` (como em `Concluir`), a menos que eu peça outra abordagem.
